Aulia: um assistente que monta a próxima aula, com o professor no controleAulia: an assistant that prepares the next lesson, with the teacher in control

Queria que o professor conseguisse preparar a próxima aula no Aulia sem começar do zero. Construí um assistente de conversa que parte da semana do próprio professor: encontra a próxima aula ainda sem plano, discute uma ideia e, depois da autorização, escreve o plano completo no tom dele, usando como referência uma aula que ele mesmo já escreveu. O assistente pode ler à vontade, mas toda escrita para e espera confirmação. O histórico da conversa é assinado no servidor, cada confirmação vale uma única vez e o assistente age com a sessão do professor, então as regras de acesso do banco valem para ele como valem para quem está logado. A cota é conferida antes de a conversa começar, e um modelo menor conduz o diálogo enquanto um maior escreve o plano. Ao terminar, ele vincula as habilidades da BNCC escolhendo só entre códigos oficiais candidatos e conferindo a resposta contra essa lista, para que nenhum código inventado chegue a um plano entregue à coordenação. A caixa de confirmação recebe o foco ao aparecer e é anunciada por leitores de tela. Em novembro de 2026 o assistente entrou em produção, depois de um teste de ponta a ponta no site: encontrou a aula, conversou, pediu autorização e gravou o plano. I wanted teachers to be able to prepare their next lesson in Aulia without starting from scratch. I built a chat assistant that starts from the teacher's own week: it finds the next lesson that still has no plan, discusses an idea and, once approved, writes the full plan in the teacher's voice, using a lesson they wrote themselves as a reference. The assistant can read freely, but every write pauses and waits for confirmation. The conversation history is signed on the server, each confirmation can be used only once, and the assistant acts with the teacher's own session, so database access rules apply to it just as they apply to the signed-in user. Quota is checked before a conversation starts, and a smaller model runs the dialogue while a larger one writes the plan. When it finishes, it links skills from Brazil's national curriculum (BNCC), choosing only among official candidate codes and checking the answer against that list, so no invented code reaches a plan handed to school coordinators. The confirmation box receives focus when it appears and is announced by screen readers. The assistant went into production in November 2026 after an end-to-end test on the live site: it found the lesson, discussed it, asked for approval and saved the plan.
