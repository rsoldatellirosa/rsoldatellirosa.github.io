Cobrança extra de banda: de US$ 113,43 a zeroBandwidth overage: from US$ 113.43 to zero

Investiguei uma cobrança de banda que crescia na DigitalOcean. Medi o tráfego dos servidores e identifiquei que, após a separação entre aplicação e banco, os workers consultavam o MySQL pelo endereço público. Os resultados das consultas passavam pela rede cobrada, mesmo entre servidores que podiam usar a rede privada. Corrigi as conexões para usar a VPC, conferindo a identidade do banco antes de cada troca. A cobrança extra caiu de US$ 113,43 em agosto para US$ 0 em setembro; outubro também estava zerado no período acompanhado. Depois criei um monitor em Python que verifica as faturas pela API e procura conexões MySQL pela rede pública, com alertas no Slack para detectar a volta do problema. I investigated a growing DigitalOcean bandwidth charge. By measuring server traffic, I found that after the application and database were separated, workers were querying MySQL through its public address. Query results crossed the billed network even between servers that could use the private network. I moved those connections to the VPC, checking the database identity before each change. The overage dropped from US$ 113.43 in August to US$ 0 in September; October was also at zero during the observation period. I then built a Python monitor that checks invoices through the API and looks for MySQL connections over the public network, with Slack alerts to detect a recurrence.
