Relatórios grandes em PDF, sem depender da impressão pelo navegadorLarge PDF reports without relying on browser printing

A impressão de relatórios de percurso pelo navegador travava com grandes volumes de posições. Criei uma ferramenta em Python para consultar os registros com operações de leitura e gerar os PDFs em lote, seguindo a lógica de agrupamento, distâncias e tempos do relatório existente. A consulta de endereços usa cache em SQLite e concorrência limitada para respeitar o serviço que atende a operação. O lote pode ser retomado sem refazer os PDFs já concluídos. Os totais de uma amostra são comparados com o relatório do sistema antes do processamento completo. O caso é descrito aqui sem relatórios reais, identificadores de veículos, trajetos, endereços ou dados de clientes. Browser printing of trip reports would stall on large volumes of position records. I built a Python tool to retrieve records through read-only operations and generate PDFs in batches, following the grouping, distance and time calculations of the existing report. Address lookup uses a SQLite cache and limited concurrency to respect the operational service. The batch can resume without rebuilding PDFs that are already complete. Sample totals are compared with the system report before processing the full batch. This case is described without actual reports, vehicle identifiers, routes, addresses or client data.
